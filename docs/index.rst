HorRAGor Technical Documentation
================================

HorRAGor is a private, observable multi-agent assistant for horror cinema. The
system ingests heterogeneous movie data, reconciles it into a canonical source
of truth, exposes retrieval through a private API, and coordinates RAG, web
investigation, and gothic narration through LangGraph.
